# Historical work

`experiments/` contains older inspection, tuning, and debugging scripts.
`exports/` contains the old ZIP export and patrol log.

These files are retained for reference and excluded from Git by default.
They are not part of the current demo. Their original paths and assumptions
have not been migrated; do not run them as current navigation tools.
Use the tasks in `.vscode/tasks.json` and the active code in `navigation/`.
